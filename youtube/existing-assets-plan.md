# 既存資産テコ入れプラン（R×R camper's channel）

> 新規動画を作るより先に、すでに再生されている動画に登録導線を足す方が費用対効果が高い、
> という前提で作った施策リスト。実行したら下部のチェックリストを埋めていく。

## 優先順位の考え方

すでに再生数・エンゲージメントが出ている動画＝「人が来ている場所」に登録動線を足すのが
最も効率的。逆に、まだ再生数の出ていない動画から手をつける優先度は低い。

| 優先度 | 対象 | 理由 |
|---|---|---|
| 🥇 最優先 | JK免許シリーズ／歩きお遍路シリーズ | 高エンゲージメント・視聴維持率が高い＝「続きが見たい」状態の視聴者が既にいる。CTA一つで転換しやすい |
| 🥈 次点 | 車・ギア・DIY系（ランクル70、ルーフトップテント等） | 検索流入の一見さんが多い＝チャンネルの存在自体を知らない可能性大。「他にもこんな動画あります」の橋渡しが必要 |
| 🥉 全体基盤 | チャンネルトップ・再生リスト・チャンネルトレーラー | 上記2つの動画から流れてきた人の受け皿。ここが弱いと個別動画の改善が漏れる |

## 具体施策（YouTubeは投稿後でも編集できる項目が対象）

### 🥇 シリーズ物（JK免許・お遍路）

- **エンドスクリーン**: 動画終了20秒で「次のエピソード」＋「チャンネル登録」の2枠を必ず設置
- **概要欄の冒頭2行**: 「◯◯シリーズ第△話。次回はこちら→[リンク]／見逃さないよう登録はこちら」
- **固定コメント**: シリーズ全話プレイリストへのリンク＋一言コメント誘導
- **プレイリスト化**: シリーズごとに専用プレイリストを作り、プレイリストの説明文にも登録導線
- **サムネイル統一**: シリーズ共通フォーマット（色・「第◯話」表記）に既存分も差し替え、
  「追いかける価値」を可視化

### 🥈 車・ギア・DIY系（資産型・検索流入）

- **概要欄末尾にクロスリンク**: 「このチャンネルでは他に〇〇シリーズもやってます」など、
  単発視聴者をシリーズ物へ橋渡し
- **エンドスクリーンで人気シリーズへ誘導**（DIY系同士で回すのではなく、
  あえてエンゲージメントの高いシリーズへ流す）
- **プレイリスト化**（車中泊・DIY・整備など）してSEO面でも回遊性を上げる

### 🥉 チャンネル全体基盤

- **チャンネルトレーラー**（未登録者向け）を、キラーコンテンツ3分類が一目でわかる構成に
- **チャンネルのプレイリスト並び順**を、資産型（検索流入）→シリーズ物（登録誘導）の
  動線になるよう整理

## 実行チェックリスト（対象動画ごとにコピーして使う）

> 動画タイトル・URLを記入し、対応したら [ ] を [x] にする。

```
### 動画: （タイトル・URLをここに）

[ ] エンドスクリーン設定済み（次回 or 登録導線）
[ ] 概要欄冒頭2行に登録/次回リンクあり
[ ] 固定コメントに導線あり
[ ] 該当プレイリストに追加済み
[ ] サムネイルがシリーズ統一フォーマットか
```

## 次のアクション

- JK免許シリーズ・お遍路シリーズの実在の動画リスト（タイトル・URL）が揃ったら、
  動画ごとの具体的なエンドスクリーン文言・固定コメント文・概要欄修正案を
  `yt-script-director` と `yt-seo-metadata` で作成し、このファイルのチェックリストに追記する
- 実行結果（登録者転換の変化など）は `youtube/channel-strategy.md` の「実績・学び」にも反映する
