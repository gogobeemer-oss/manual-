# 【コピペOK】月末の勤怠チェック、打刻漏れ・残業申請の催促をAIプロンプトで一瞬で終わらせる

月末になると憂鬱になる作業、ありませんか。打刻漏れの一覧を開いて、一人ずつ名前を確認して、「〇〇さん、お忙しいところすみません、打刻の修正をお願いします」というメールを書く。次の人にも同じような文面を、でも同じコピペだと味気ないから少し言い回しを変えて…。これを10人、20人分やっていると、それだけで小一時間が溶けます。私も元エクセル地獄の事務員として、この作業に何度もため息をついてきました。実はこの「一覧を見て、分類して、文面を作る」という作業、AIにそっくり任せられます。今日はその具体的なやり方を、コピペで使えるプロンプトつきでお伝えします。

## はじめに（打刻漏れ催促メールを一人ずつ書いていた頃の話）

前職で勤怠管理の補助をしていたとき、月末の3日間くらいは「打刻漏れ・申請漏れの催促」に時間を溶かしていました。勤怠システムから未提出者リストを出力して、一人ひとりの名前と日付を見ながら、Outlookでメールを書く。文面はだいたい同じなのに、毎回一から打つのが地味にしんどい。かといって定型文の一斉送信だと「事務的すぎて冷たい」とクレームが来たこともあり、結局手作業に戻っていました。おまけに残業時間が多い人のチェックも別作業で、一覧を目で追いながら「この人今月45時間超えてるな…」と拾っていく。正直、この時間があれば他の仕事が進むのにと思っていました。

## なぜ勤怠チェックにAIが使えるのか

ここで発想を変えてみます。AIが得意なのは「大量のテキストを読んで、パターンを見つけて、文章に整える」ことです。勤怠チェックの作業って、まさにこれの繰り返しなんですよね。

- 未提出者リストを見て → 一人ひとりに催促メールを書く（＝文章生成）
- 稼働時間の一覧を見て → 基準を超えている人を拾う（＝パターン認識）
- 部署ごとの残業傾向を見て → 報告文にまとめる（＝要約）

つまり、勤怠データを「テキストの形」にしてAIに渡してしまえば、チェックも文面作成もまとめて肩代わりしてもらえるということです。Excelの一覧をコピーして、チャット画面に貼り付けるだけ。特別なツールやシステム連携は一切いりません。これだけでも、月末の作業感がだいぶ変わります。

## 使う前に知っておきたいNGポイント（個人情報の扱い・社内規定）

ただし、ここで絶対に押さえておきたい注意点があります。勤怠データには氏名や勤務時間といった個人情報が含まれます。これを実名のまま、無制限に外部のAIサービスに入力するのはNGです。会社によっては社内規定で「個人情報を外部サービスに入力してはいけない」と明確に定めているところもあるので、まずは自分の会社の情報セキュリティルールを確認してください。

その上で私がやっているのが「仮名化」です。実名を使わず、Aさん・Bさんとか、社員番号の一部だけ、あるいはイニシャルに置き換えてからAIに渡します。日付や時間はそのまま使っても大きな問題になりにくいので、「誰か」が特定できない形にするのがポイントです。あとで自分の手元でAさん＝〇〇さん、と対応表を見ながら本名に戻せば大丈夫です。この一手間さえ挟めば、AIを安心して使えます。

ここから先の有料パートでは、この仮名化の具体的なやり方も含めて、実際にそのままコピペして使える3つのプロンプトと、催促メール＆異常値チェックの作業時間がどう変わったかの実例をお見せします。

### ここから先は有料パートです

ここから先では、①打刻漏れ・申請未提出者への催促メールを一括生成するプロンプト（やわらかい表現・厳しめ表現の2パターン）、②残業超過・休日出勤過多などの異常値を自動でリストアップするプロンプト、③部署ごとの残業傾向を報告文にまとめるプロンプトを、すべてそのままコピペできる形で公開します。あわせて、一人5分かかっていた作業が実際どれくらい短縮できたかの数字と、個人情報の仮名化の具体的な手順もQ&Aでお伝えします。

## 【コピペOK】打刻漏れ・申請未提出者への催促メール作成プロンプト

まずはExcelの未提出者一覧を、名前（仮名でOK）と日付だけシンプルにテキスト化してコピーしておきます。

**やわらかい表現バージョン**

```
以下は打刻漏れ・申請未提出の人のリストです。
[Aさん 7/3, Bさん 7/10, Cさん 7/15, 7/16]

それぞれの人に向けて、打刻修正・申請提出をお願いするメール文面を、
一人ずつ分けて作ってください。
条件は以下の通りです。
・やわらかく丁寧な口調で、責めている印象にならないようにする
・「お忙しいところ恐れ入りますが」など気遣いの一言を入れる
・修正期限は今月末とする
・件名も一緒につけてください
```

**厳しめ表現バージョン（何度も未提出が続いている人向け）**

```
以下は打刻漏れ・申請未提出が今月2回目以上の人のリストです。
[Dさん 7/2・7/18, Eさん 7/8・7/22]

それぞれの人に向けて、期限厳守での修正・提出をお願いするメール文面を作ってください。
条件は以下の通りです。
・丁寧語は保ちつつ、期限を守ってほしいという意図がはっきり伝わる文面にする
・繰り返しになっている旨をやわらかく指摘する
・提出期限を明記する（例：7/25 17時まで）
・件名も一緒につけてください
```

このまま貼り付けるだけで、人数分の文面を一気に出してくれます。あとは仮名を本名に戻して、そのまま送るだけです。

## 【コピペOK】残業超過・異常値チェックプロンプト

続いて、稼働時間の一覧（氏名・所定時間・実働時間・休日出勤日数など）をテキスト化してコピーします。

```
以下は今月の勤怠一覧です（氏名・実働時間・休日出勤日数）。
[Aさん 実働182h 休日出勤0日, Bさん 実働201h 休日出勤2日, Cさん 実働165h 休日出勤0日]

このリストから、下記の基準に当てはまる人をリストアップしてください。
・月の実働時間が195時間を超えている人
・休日出勤が2日以上ある人
それぞれ「誰が」「どの基準に該当するか」「具体的な数値」がわかる形で
一覧表にして出力してください。
```

基準の数字は自社の就業規則に合わせて変えてください。この一覧が出たら、上長への確認や本人への声かけの優先順位がその場でわかります。目視で一人ずつ数字を追う必要がなくなるのが大きいです。

## 【コピペOK】月末勤怠サマリー作成プロンプト

最後に、上司への報告用に使えるサマリー作成のプロンプトです。

```
以下は部署ごとの今月の残業時間の平均データです。
[営業部 平均残業28h, 総務部 平均残業12h, 開発部 平均残業35h]

このデータをもとに、上司への月次報告用の文章を作成してください。
条件は以下の通りです。
・数字だけでなく、先月と比べて増減の傾向がありそうな部署に触れる形の文章にする
・過度に危機感をあおらず、事実ベースで簡潔にまとめる
・箇条書きではなく、400字程度の報告文にする
```

先月分の数字も一緒に渡せば、増減の比較コメントまで自動で入れてくれます。私はこれをコピーして、そのまま報告メールの本文に貼り付けています。

## Before/After：チェック＆催促にかかる時間はここまで変わった

実際に私が試した体感の数字です。

- 催促メール作成：1人あたり約5分 → 10人分をまとめて依頼して待ち時間込みで約3分
- 残業超過者の洗い出し：一覧を目で追って約20分 → プロンプトに貼り付けて約1分
- 月次サマリー作成：文章を考えながら約15分 → たたき台が数秒で出てきて、微調整含め約5分

月末の勤怠チェック全体で、体感1時間半かかっていた作業が20〜30分程度に収まるようになりました。空いた時間で他の締め作業に回せるのが一番のメリットです。

## 個人情報の扱いQ&A（仮名化のコツ）

**Q. 仮名化ってどこまでやればいいですか？**
A. 氏名を「Aさん」「B様」など記号化するだけで十分です。日付や勤務時間の数字はそのまま使っても、それ単体では個人を特定できないので問題になりにくいです。心配な場合は所属部署名もぼかしておくとより安心です。

**Q. 仮名を本名に戻す作業が面倒じゃないですか？**
A. 私はExcelに「仮名／本名」の対応表を作っておき、AIが出した文面のAさん・Bさんの部分を検索置換で一括変換しています。これなら数秒で終わります。

**Q. 社内規定で外部AIの利用が禁止されている場合は？**
A. まずは総務・情報システム部門に確認するのが一番です。会社が契約している法人向けAIツールがあれば、そちらを使うのが安全です。個人の判断で規定を破らないよう注意してください。

## まとめ

打刻漏れの催促メールも、残業超過者のチェックも、月次サマリーも、全部「テキストにしてAIに渡す」だけで驚くほど時短できます。ポイントは、実名のまま渡さず仮名化する一手間を忘れないこと。これさえ守れば、月末の憂鬱な作業がぐっと軽くなります。今回のプロンプトはぜひそのままコピペして、来月末の勤怠チェックで試してみてください。使ってみた感想やアレンジ例があれば、コメントで教えてもらえると嬉しいです。次回は「経費精算のチェックもAIに任せる」編をお届け予定です。
