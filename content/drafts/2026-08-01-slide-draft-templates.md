# 【コピペOK】資料作成が3分の1の時間で終わる、AIプロンプトテンプレ集（パワポ下書き編）

「とりあえず資料まとめといて」と言われて、真っ白なパワポを開いたまま固まったこと、ありませんか。私は元エクセル地獄の事務員で、デザインセンスもゼロ、文章を要約するのも大の苦手でした。でも今は、AIに下書きを手伝ってもらうことで、資料作りの時間がだいぶ短くなりました。この記事では、私が実際に使っているコピペOKのプロンプト（AIへの指示文）をそのままお渡しします。専門用語は出てきませんので、パソコン作業が苦手な方も安心して読んでください。

## はじめに（真っ白なパワポで固まった話）

以前の私は、「会議資料、明日までにお願い」と言われるたびに胃が痛くなっていました。パワポを開いても、何から書けばいいのか分からない。とりあえずタイトルだけ入力して、あとは白紙のまま30分経過…なんてことがザラでした。

構成を考えるのが苦手だったんです。伝えたいことはぼんやりあるのに、それを「見出し」という形に整理できない。結局、思いつきで箇条書きを並べて、上司に「で、結局何が言いたいの？」と聞かれる。そんな繰り返しでした。

## 資料作成、AIに向いてる部分・向いてない部分

AIを使い始めて分かったのは、「全部AIに任せる」のではなく、役割分担することが大事だということです。

- **AIが得意なこと**：構成（章立て）のたたき台作り、長い文章の要約、文章のトーン調整
- **AIが苦手・不向きなこと**：デザインや配色、社内独自のルールを踏まえた最終チェック、数字や事実の正確さの確認

つまり、「叩き台を作るのはAI、仕上げと確認は自分」という分担にすると、一番ラクになります。AIに「白紙から全部いい感じにして」とお願いするとふわっとした答えしか返ってきませんが、「この目的で、この結論を伝えたい」と具体的に伝えると、驚くほど使える下書きが返ってきます。

## ミニ実演：見出し案を1つ出してもらう

試しに、こんな指示をAIに出してみます。

> 「新商品の販促資料を作りたいです。読み手は営業部のメンバーです。見出し案を1つ考えてください」

これだけでも、AIは「1. 商品の特徴／2. ターゲット顧客／3. 販売戦略」のような見出し案を返してくれます。もちろん1つの見出し案だけでは資料は完成しませんが、「白紙から自分でひねり出す」のと「AIの案を見ながら選ぶ・直す」のとでは、かかる時間も気持ちの重さも全然違います。

ここから先では、私が実際に使っている「章立て全体を作るプロンプト」「長文をスライド1枚分に要約するプロンプト」「社内向け・社外向けでトーンを変えるプロンプト」を、そのままコピペできる形でお渡しします。実際のAIとのやり取りの例と、資料作成にかかった時間がどれくらい変わったかも、具体的な数字でご紹介します。

### ここから先は有料パートです

ここから先は、明日の会議資料からすぐ使える「コピペOKプロンプト」を3種類、実際のAIとの会話例つきで公開します。読み終わったら、次に資料を作るときにコピペするだけで、構成に悩む時間をほぼゼロにできます。

## 【コピペOK】章立て・構成案作成プロンプト

まずは、資料全体の骨組みを作ってもらうプロンプトです。以下をそのままAIにコピペしてください。

```
これから作る資料のテーマは「　　　」、
伝えたい結論は「　　　」です。
読み手は「　　　」（例：営業部/上司/取引先）です。
スライドの章立て案を5つくらい、見出しだけの箇条書きで出してください。
専門用語は使わず、シンプルな言葉でお願いします。
```

**実際のやり取り例**

私：「テーマは『新しい経費精算システムの導入案内』、結論は『来月から全員このシステムに切り替える』です。読み手は経理以外の一般社員です。章立て案を5つ出してください」

AI：
1. なぜ切り替えるのか（背景と目的）
2. 新システムでできること
3. これまでとの違い（何が変わるか）
4. 使い方の流れ（3ステップで説明）
5. 質問・サポート窓口の案内

このまま使ってもいいですし、「4番をもっと具体的にして」と追加でお願いすれば、そこだけ深掘りしてくれます。白紙から考えると40分かかっていた構成出しが、これだと8分くらいで終わります。

## 【コピペOK】スライド要約文作成プロンプト

長いメモや議事録を、スライド1枚分の箇条書きに変換してもらうプロンプトです。

```
以下の文章を、スライド1枚分の要約にしてください。
箇条書き3行程度、1行は30文字以内でお願いします。
一番伝えたいポイントを最初に置いてください。

【ここに元の文章を貼り付け】
```

たとえば、5分の打ち合わせメモ（400字くらい）をそのまま貼り付けると、

- 来月から新システムへ全面移行
- 操作研修は来週3回に分けて実施
- 不明点は情報システム部の窓口へ

というように、スパッと3行にまとめてくれます。自分で要約しようとすると「あれもこれも大事な気がする」と削れなくなりがちですが、AIは容赦なく削ってくれるので、そこから「これは残したい」と自分で足し引きする方が結局早いです。

## 【コピペOK】トーン別（社内向け／社外向け）言い換えプロンプト

同じ内容でも、社内向けと社外向けでは言葉遣いを変える必要があります。これも指示ひとつで変換できます。

**フォーマルver（社外・取引先向け）**
```
以下の文章を、取引先に送る資料として使える
フォーマルな言い回しに書き直してください。
丁寧すぎて硬くなりすぎない程度でお願いします。

【ここに元の文章を貼り付け】
```

**カジュアルver（社内・チーム向け）**
```
以下の文章を、社内の同僚向けに、
親しみやすく分かりやすい言い回しに書き直してください。
堅苦しい表現は避けてください。

【ここに元の文章を貼り付け】
```

同じ「値上げのお知らせ」でも、フォーマルverだと「誠に恐縮ではございますが、来月より価格を改定させていただきます」、カジュアルverだと「来月から少し値段が上がります、ご了承ください」というように、トーンだけ変えてくれます。資料の使い回しがぐっと楽になります。

## Before/After：資料作成にかかる時間はここまで変わった

私が実際に計測した数字です（社内向け報告資料・スライド8枚の場合）。

| 工程 | AI導入前 | AI導入後 |
|---|---|---|
| 構成を考える時間 | 約40分 | 約8分 |
| 各スライドの文章下書き | 約60分 | 約20分 |
| トーン調整・言い換え | 約15分 | 約5分 |
| **合計** | **約115分** | **約33分** |

だいたい3分の1以下の時間で下書きまで到達できるようになりました。もちろん、最終的なデザイン調整や事実確認は自分でやる必要がありますが、「白紙から何を書くか悩む時間」がなくなるだけで、精神的な負担もかなり軽くなります。
