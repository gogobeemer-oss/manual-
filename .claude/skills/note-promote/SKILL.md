# note記事の告知文生成

`growth-strategist` サブエージェントを使い、指定された記事（`content/published/` 内、
または未公開ならユーザーが渡すURL・本文）に対して告知文を生成する。

## 手順

1. 対象記事の本文（または要点）を読み、フックになりそうなポイントを3つ程度抽出する
2. 以下のバリエーションを生成する
   - X(旧Twitter)投稿文（140字前後、1〜2案）
   - X投稿用のスレッド形式（記事の要点を3〜5ツイートに分割、任意）
   - note内シェア用の短い一言コメント
3. 有料記事の場合は「無料で読める部分の価値」を見せつつ、有料パートへの興味を引く文言にする
4. ハッシュタグは過剰に付けず、関連性の高いものを2〜3個に絞って提案する

## 注意

- 実際の投稿はユーザー自身が行う（このスキルは文章生成のみ）
- 誇大表現・釣りタイトル化を避け、記事内容と一致した訴求にする
