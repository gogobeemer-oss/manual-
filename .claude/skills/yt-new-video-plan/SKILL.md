# R×R camper's channel 新動画企画ワークフロー

4つのサブエージェント（Lead Strategist / Thumbnail & Title / Script Director / SEO Optimizer）を
順番に連携させ、投稿前の企画書を `youtube/video-plans/` に作成する。

## 手順

1. ユーザーから動画テーマ・撮影素材の概要を受け取る（曖昧なら1つだけ質問して確認する）
2. `youtube/channel-strategy.md` を読み、既存のキラーコンテンツ分類・実績・課題を把握する
3. **現状評価（yt-lead-strategist）**: どのキラーコンテンツの派生・応用か、
   チャンネル登録率（CVR）改善の観点で企画をどう活かすかを評価させる
4. **タイトル・サムネ（yt-thumbnail-title）**: タイトル案5選とサムネイルデザイン案
   （メインコピー、サブコピー、配置・色指定）を作らせる
5. **構成・CTA（yt-script-director）**: オープニングフック、チャプター構成、
   チャンネル登録CTAの挿入ポイントを設計させる
6. **SEO・メタデータ（yt-seo-metadata）**: 概要欄、タグ、ハッシュタグ、タイムスタンプ、
   （該当する場合）英語タイトル・概要を作らせる
7. 以下の形式で企画書をまとめ、`youtube/video-plans/<YYYY-MM-DD>-<スラッグ>.md` に保存する
   - 【チーム視点での現状評価】
   - 【タイトル案（5選）】
   - 【サムネイルデザイン案】
   - 【オープニング〜中間構成・CTA設計】
   - 【概要欄・ハッシュタグ・SEOテキスト】
8. 保存したファイルの場所と企画の要点をユーザーに報告する

## 注意

- YouTubeには投稿APIとの連携を前提としないため、このスキルは企画書をこのリポジトリに
  作るところまでを行う。実際の動画編集・投稿はユーザー自身が行う
- 公開後の実績（登録者転換率・視聴維持率など）が本人から報告されたら、
  `youtube/channel-strategy.md` の「実績・学び」に記録し、`youtube/published/` にも
  企画書を移動してアーカイブする
