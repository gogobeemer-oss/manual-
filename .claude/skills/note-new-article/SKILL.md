# note新規記事作成ワークフロー

企画・執筆・編集の3エージェントを順番に連携させ、投稿可能な下書きを `content/drafts/` に作成する。

## 手順

1. **企画（content-planner）**: ユーザーからテーマ・要望を受け取り（曖昧なら1つだけ質問して確認する）、
   `content-planner` サブエージェントにタイトル案・想定読者・無料/有料の切り分け・構成骨子を作らせる
2. ユーザーに企画案を提示し、方向性の確認を取る（大きく手戻りしないよう、書き始める前に1回だけ確認）
3. **執筆（writer）**: 承認された企画を `writer` サブエージェントに渡し、本文を執筆させる。
   `content/drafts/<YYYY-MM-DD>-<スラッグ>.md` として保存する
4. **編集（editor）**: 書き上がった下書きを `editor` サブエージェントにレビュー・修正させる
5. 最終的な下書きの場所と、編集サマリー（直した点・投稿前に確認してほしい点）をユーザーに報告する

## 注意

- note には投稿APIがないため、このスキルはあくまで「下書きをこのリポジトリに作る」ところまでを行う。
  実際の note への投稿はユーザー自身が行う
- 有料記事か無料記事かは企画段階で必ず決め、editorにもその前提を伝える
- 大きな方向転換（テーマ変更など）が必要になった場合は、書き進める前に必ずユーザーに確認する
